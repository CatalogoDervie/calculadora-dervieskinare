# Guía de conexión

1. Subir `index.html`, `style.css`, `script.js`, `config.js`, `.nojekyll` y `README.md` al repo de GitHub.
2. Activar GitHub Pages desde `Settings > Pages > main / root`.
3. Abrir la planilla base.
4. Ir a `Extensiones > Apps Script`.
5. Pegar `apps-script/Code.gs`.
6. Ejecutar `inicializarBase` y aceptar permisos.
7. Implementar como `Aplicación web`.
8. Configurar: `Ejecutar como: Yo` y `Acceso: Cualquier persona`.
9. Copiar la URL que termina en `/exec`.
10. Pegar esa URL en `config.js` en `API_URL`.
11. Probar desde la página: Config. > Probar conexión.

# Estructura de Google Sheets

El sistema usa estas hojas:

## Configuracion

```text
Campo
Valor
```

Guarda parámetros generales.

## Productos

```text
ID_PRODUCTO
CODIGO
PRODUCTO
DESCRIPCION
CATEGORIA
PRECIO_COSTO
PRECIO_REVENTA
PRECIO_VENTA_SUGERIDO
PRECIO_VENTA_PROPIO
STOCK_ACTUAL
STOCK_MINIMO
ACTIVO
CANT_DESC_1
DESC_1
CANT_DESC_2
DESC_2
FECHA_ACTUALIZACION
```

Notas:

- `PRECIO_COSTO`: lo que vos pagás.
- `PRECIO_REVENTA`: lo que la médica / centro te paga a vos.
- `PRECIO_VENTA_SUGERIDO`: precio al paciente, solo informativo.
- `STOCK_MINIMO`: usado para alertas.
